This project is published for **educational and preservation purposes**.

## Engine

The core engine code (C++) is a reimplementation of the Heart of Darkness engine,
reverse-engineered by **Gregory Montoir** and published at [github.com/cyxx/hode](https://github.com/cyxx/hode).

The upstream repository has been archived (November 2023) and does not specify a license.
All engine code remains the work of its original author.

## Android Port

The Android-specific additions (Kotlin/Java UI, touch overlay, SVG icon system, SAF importer,
Gradle build system) are provided as-is for educational use. These additions may be freely
studied, modified, and redistributed for non-commercial preservation purposes.

## Game Data Files

**No Heart of Darkness game data files are included in this repository.**

Heart of Darkness (1998) is copyrighted by Amazing Studio / Infogrames. You must own
a licensed copy of the game to use this software. The file hashes in RELEASES.yaml
serve only to identify compatible game versions and do not constitute game data.
